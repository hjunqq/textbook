5.1 后端服务概述
什么是后端服务器
定义：后端服务是应用程序中的一部分，负责处理客户端发出的请求，执行业务逻辑，
与数据库交互，并将结果返回给客户端。它通常运行在服务器端，不直接与用户交互，
而是通过API（应用程序编程接口）与前端应用或其他服务通信。
后端服务的组成：包括数据存储层（如数据库）、应用逻辑层（如业务处理）、以及接
口层（如RESTful API或GraphQL等）。
后端的角色：后端服务作为前端与数据的桥梁，确保应用程序能够正确处理用户请求并
返回数据。例如，用户在电商网站搜索商品，后端服务会从数据库中获取匹配的商品信
息并返回给前端显示。

第6页:
5.1 后端服务概述
HTTP 方法
• HTTP 定义了一组请求方法，以表明要对给定资源执行的操作。指示针对给定资源要执行的期望动作。
虽然它们也可以是名词，但这些请求方法有时被称为 HTTP 动词。每一个请求方法都实现了不同的语
义，但一些共同的特征由一组共享：例如一个请求方法可以是安全的、幂等的或可缓存的。
GET
• GET 方法请求一个指定资源的表示形式，使用 GET 的请求应该只被用于获取
数据。
POST
• POST 方法用于将实体提交到指定的资源，通常导致在服务器上的状态变化或
副作用。
PUT
• PUT 方法用有效载荷请求替换目标资源的所有当前表示。
DELETE
• DELETE 方法删除指定的资源。
PATCH
• PATCH 方法用于对资源应用部分修改。

5.1 后端服务概述
Web应用框架
• 服务器端框架 (亦称 "web 应用框架") 使编写、维护和扩展 web 应用更加容易。
• 提供工具和库来实现简单、常见的开发任务，包括 路由处理，数据库交互，会话支持和用户验证，
格式化输出 (e.g. HTML, JSON, XML), 提高安全性应对网络攻击。
在后端服务开发中，有很多工具和框架可以
选择，可以快速、稳定地搭建服务。
• Spring Boot：这是一个基于Java的非常流
行的后端框架，适合大中型应用开发。它提
供了大量的功能模块（例如数据库连接、用
户管理等），可以大大减少开发的时间。
• Flask：这是一个基于Python的轻量级后端
框架，特点是简单灵活，非常适合中小型应
用或者快速原型开发。
