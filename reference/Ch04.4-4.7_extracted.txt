框架提供的功能
• 工具
• 由于此模块中的每个框架都有一个庞大而活跃的社区，因此每个框架的体系都提供了工具来改善开发体验。
这些工具让诸如添加测试（确保你的应用表现应有的行为）和 linting（确保你的代码没有错误且排版统一）
变得更加容易。
• 组件化
• 大多数框架都鼓励开发者将其用户界面的不同部分抽象为组件（components）——可维护、可重用且可以相
互通信的代码块。
• 路由
• Web 最重要的特点是它允许用户从一个页面导航到另一个页面
现代 Web 应用程序通常不会获取和
渲染新的 HTML 文件——它们加载
单个 HTML shell，并不断更新其中
的 DOM 而无需将用户导航到 Web
上的新地址。(这被称为单页应用程
序（single page app） 或 SPA)。

VUE简介
• Vue.js 是一个用于构建用户界面的渐进式JavaScript框架。与其他大型框架不同，Vue被设计为自底
向上逐层应用。
在为AngularJS工作之后，Vue的作者尤雨溪开发出了这一框架。他声称自己的思路是提取
Angular中为自己所喜欢的部分，构建出一款相当轻量的框架。
Vue最早发布于2014年2月。
Vue是Github上最受欢迎的开源项目之一。
• 核心目标：
• 通过响应式的数据绑定和灵活的组件系统，简化开发过程，提高代码的复用性和可维护性。
• 与HTML、CSS、JavaScript的关系：
• Vue.js 是基于这些技术构建的，它不会替代这些技术，而是帮助更高效地管理复杂的前端逻辑。
