## 🚀 如何应用到新教材

### 第一步：复制模板包
```bash
# 将模板包复制到新教材项目
cp -r "教材模板包" "我的新教材项目"
cd "我的新教材项目"
```

### 第二步：准备内容
按照以下结构组织您的Markdown文件：
```
我的新教材/
├── 第一章/
│   ├── 1.1节内容.md
│   ├── 1.2节内容.md
│   ├── 本章小结.md
│   ├── 思考题.md
│   └── images/
├── 第二章/
│   └── ...
└── config.json  # 配置文件
```

### 第三步：一键转换
```bash
# Windows用户
转换脚本\通用转换.bat . -f pdf

# 或使用Python脚本
python 转换脚本/通用教材转换器.py . -f pdf
```

### 第四步：质量检查
```bash
python 质量控制/质量检查器.py . -o 质量报告.txt
```
