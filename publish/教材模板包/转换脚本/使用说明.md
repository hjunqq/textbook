# 修复后的教材转换脚本使用说明

## 主要修复内容

### 🔧 修复的问题

1. **LaTeX文档结构问题**
   - ❌ 原问题：章节文件包含 `\documentclass`、`\usepackage` 等preamble命令
   - ✅ 修复方案：章节文件只包含纯内容，所有命令定义在主文件中

2. **缺失命令定义**
   - ❌ 原问题：`\tightlist`、`\onehalfspacing`、`\real` 等命令未定义
   - ✅ 修复方案：在主文件中预定义所有必要命令

3. **Emoji字符支持问题**
   - ❌ 原问题：LaTeX字体不支持emoji，导致编译警告/错误
   - ✅ 修复方案：自动识别并移除/替换emoji字符

4. **图片路径混乱**
   - ❌ 原问题：图片路径不统一，存在 `images/../images/` 等错误路径
   - ✅ 修复方案：统一管理到 `images/` 目录，自动复制和修复路径

5. **包依赖管理**
   - ❌ 原问题：缺少必要的LaTeX包，重复引入包
   - ✅ 修复方案：完整的包依赖列表，去重处理

## ⚙️ 配置选项

修改 `配置文件示例.json` 来自定义转换选项：

```json
{
    "preprocessing": {
        "remove_emojis": true,        // 是否移除emoji
        "optimize_images": true,       // 是否优化图片路径
        "fix_code_blocks": true        // 是否修复代码块
    },
    "postprocessing": {
        "fix_document_structure": true,  // 是否修复文档结构
        "beautify_layout": true          // 是否美化布局
    },
    "latex_settings": {
        "chinese_font_main": "SimSun",   // 中文主字体
        "chinese_font_sans": "SimHei",   // 中文无衬线字体
        "chinese_font_mono": "FangSong"  // 中文等宽字体
    }
}
```

## 🔍 故障排除

### 常见问题

1. **Python不可用**
   - 确保已安装Python 3.6+
   - 确保Python已添加到系统PATH

2. **Pandoc不可用**
   ```bash
   # Ubuntu/Debian
   sudo apt-get install pandoc
   
   # Windows
   # 从 https://pandoc.org/installing.html 下载安装
   ```

3. **LaTeX编译器不可用**
   ```bash
   # Ubuntu/Debian
   sudo apt-get install texlive-full
   
   # Windows
   # 安装MikTeX或TeX Live
   ```

4. **编译错误**
   - 检查日志文件（`教材.log`）中的具体错误
   - 确保所有图片文件存在
   - 检查中文字体是否安装

### 调试步骤

1. **检查源文件**
   ```bash
   python 修复后的通用教材转换器.py /path/to/docs -f latex
   # 先生成LaTeX文件，检查内容是否正确
   ```

2. **手动编译测试**
   ```bash
   cd 输出目录
   xelatex 教材.tex
   # 查看具体的编译错误
   ```

3. **图片检查**
   - 确保所有引用的图片文件都存在
   - 检查图片格式是否支持（PNG、JPG、SVG、PDF）
