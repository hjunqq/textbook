\section{Web基础概念与浏览器架构}

浏览器通过HTTP或HTTPS请求资源，解析HTML形成DOM树，解析CSS形成CSSOM树，再计算布局并绘制页面；JavaScript通过事件循环处理用户操作、网络响应和定时任务。智慧水利页面常同时展示地图、曲线与告警，因此应避免在短时间内反复修改大量DOM节点。

现代浏览器通常采用多进程架构。图\ref{fig:browser-architecture}强调各模块的协作关系：浏览器引擎负责协调，渲染引擎使用网络模块取得的资源，调用JavaScript引擎执行脚本，并通过UI后端绘制；存储模块为浏览器引擎及页面脚本提供受控的数据持久化能力。

浏览器兼容性应通过标准API、特性检测和自动化测试控制。例如，应检测\texttt{WebSocket}是否存在，再决定使用实时连接还是降级到轮询，而不能只依据浏览器名称。资源缓存则应由HTTP缓存头控制；监测实时值不宜与长期静态资源采用同一缓存策略。

\section{HTML基础与语义化}

HTML描述内容的结构和语义。\texttt{header}、\texttt{nav}、\texttt{main}、\texttt{section}、\texttt{article}与\texttt{footer}等元素能够表达区域含义，有助于无障碍工具、搜索引擎和开发者理解页面。标题级别应连续，表单控件应有\texttt{label}，图片应提供\texttt{alt}文本。

下面的页面骨架只负责内容组织，不在HTML中混入具体视觉样式。

\begin{lstlisting}[language=html]
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>水库监测</title>
  <link rel="stylesheet" href="monitor.css">
</head>
<body>
  <header><h1>水库监测</h1></header>
  <nav aria-label="主导航"><a href="#level">实时水位</a></nav>
  <main><section id="level" aria-labelledby="level-title">
    <h2 id="level-title">实时水位</h2>
    <output id="level-value">4.20 m</output>
  </section></main>
  <footer>数据更新时间：<time datetime="2026-08-05T08:00:00+08:00">08:00</time></footer>
</body>
</html>
\end{lstlisting}

表格适合表达二维数据，不应用于页面布局。水位表至少应包含表头、单位和测量时间；表单提交前还需结合业务规则校验站点、时间范围和数值边界。

\section{CSS样式与响应式布局}

CSS负责视觉呈现。规则由选择器和声明块组成，层叠结果主要受来源、优先级和出现顺序影响。工程中宜使用类选择器组织组件样式，避免依赖过深的DOM层级。

\begin{lstlisting}[language=CSS]
:root { --normal: #1677ff; --warning: #d46b08; }
.monitor-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(12rem, 1fr));
  gap: 1rem;
}
.monitor-card {
  padding: 1rem;
  border: 1px solid #d9e2ec;
  border-radius: .5rem;
  background: #fff;
}
.monitor-card--warning { border-left: .35rem solid var(--warning); }
@media (max-width: 768px) {
  .monitor-grid { grid-template-columns: 1fr; }
}
\end{lstlisting}

Grid适合仪表盘的二维区域布局，Flexbox适合工具栏等一维排列。响应式设计不能只缩小字号，还应调整列数、触控目标和信息优先级。上例在窄屏上改为单列，读者可以进一步用浏览器的设备模拟器检查断点前后的卡片顺序、触控区域和滚动方向。

\section{JavaScript基础编程}

现代JavaScript使用\texttt{const}声明不重新赋值的绑定，使用\texttt{let}声明需要变化的绑定。基本类型包括数字、字符串、布尔值、\texttt{null}、\texttt{undefined}、\texttt{bigint}与\texttt{symbol}；对象、数组和函数属于引用类型。

字符串可用模板字面量组合，也可通过\texttt{trim()}、\texttt{includes()}、\texttt{slice()}和\texttt{split()}完成常见处理。完成字符串处理后，再使用比较、逻辑和算术运算符表达业务规则。例如，某水库汛期警戒水位统一设为5.0米：

\begin{lstlisting}[language=JavaScript]
const stationName = "东湖水库";
const warningLevel = 5.0; // 单位：m，本章同一示例场景统一采用该阈值
const reading = { stationId: "ST-01", level: 5.12, unit: "m" };
const status = reading.level >= warningLevel ? "预警" : "正常";
const message = `${stationName}：${reading.level} ${reading.unit}，${status}`;
console.log(message.trim());
\end{lstlisting}

数组常用\texttt{map()}完成映射、\texttt{filter()}完成筛选、\texttt{reduce()}完成聚合；对象解构可以明确取出字段。函数应保持单一职责并显式返回结果。

\begin{lstlisting}[language=JavaScript]
const readings = [4.72, 5.12, 4.95];
const alarms = readings
  .filter(level => level >= 5.0)
  .map(level => ({ level, severity: "warning" }));

function validateLevel(level) {
  if (!Number.isFinite(level)) throw new TypeError("水位必须是数字");
  if (level < 0 || level > 50) throw new RangeError("水位超出测站量程");
  return level;
}
\end{lstlisting}

\subsection{异常处理}

\texttt{try}包围可能失败的操作，\texttt{catch}处理异常，\texttt{finally}执行清理。异常不能被静默吞掉，应在界面给出可理解提示，并把技术细节记录到日志系统。

\begin{lstlisting}[language=JavaScript]
function parseReading(raw) {
  try {
    const reading = JSON.parse(raw);
    return { ok: true, level: validateLevel(reading.level) };
  } catch (error) {
    console.error("监测数据解析失败", error);
    return { ok: false, message: "数据暂不可用" };
  }
}
\end{lstlisting}

\section{异步编程与Promise}

Promise有pending、fulfilled和rejected三种状态。\texttt{then()}返回新的Promise，因此可把“取数—解析—呈现”组织成链；链末使用\texttt{catch()}集中处理失败。

\begin{lstlisting}[language=JavaScript]
function loadLatestLevel(stationId) {
  return fetch(`/api/stations/${stationId}/latest`)
    .then(response => {
      if (!response.ok) throw new Error(`HTTP ${response.status}`);
      return response.json();
    })
    .then(data => ({
      stationId: data.stationId,
      level: validateLevel(data.level)
    }));
}

loadLatestLevel("ST-01")
  .then(reading => console.log("最新水位", reading.level))
  .catch(error => console.error("加载失败", error));
\end{lstlisting}

\texttt{async/await}用于以顺序形式表达同样的异步过程。彼此独立的请求应通过\texttt{Promise.all()}并发执行；有依赖关系的请求才顺序等待。

\begin{lstlisting}[language=JavaScript]
async function loadDashboard(stationId) {
  try {
    const [latest, alarms] = await Promise.all([
      fetch(`/api/stations/${stationId}/latest`),
      fetch(`/api/stations/${stationId}/alarms`)
    ]);
    if (!latest.ok || !alarms.ok) throw new Error("接口响应异常");
    return { latest: await latest.json(), alarms: await alarms.json() };
  } catch (error) {
    console.error("仪表盘加载失败", error);
    throw error;
  }
}
\end{lstlisting}

需要取消过期请求时可使用\texttt{AbortController}。例如用户快速切换测站，应取消前一测站尚未完成的请求，避免旧响应覆盖新页面。

\section{DOM操作与事件处理}

DOM是HTML文档在浏览器中的对象表示。优先使用\texttt{querySelector()}定位元素、\texttt{textContent}写入文本、\texttt{classList}切换状态。不要把未经转义的外部数据写入\texttt{innerHTML}。

下面示例完整展示事件绑定、输入校验和界面更新。警戒值仍为同一场景的5.0米。

\begin{lstlisting}[language=html]
<label for="level-input">水位（m）</label>
<input id="level-input" type="number" step="0.01">
<button id="check-level" type="button">判断状态</button>
<output id="level-result" aria-live="polite"></output>
<script>
  const input = document.querySelector('#level-input');
  const result = document.querySelector('#level-result');
  document.querySelector('#check-level').addEventListener('click', () => {
    const level = Number(input.value);
    if (!Number.isFinite(level)) {
      result.textContent = '请输入有效水位';
      return;
    }
    result.textContent = level >= 5.0 ? '达到警戒水位' : '水位正常';
  });
</script>
\end{lstlisting}

高频监测数据不应逐条触发复杂布局。可以先把数据聚合到内存，再按固定帧率更新图表；列表较长时采用分页或虚拟滚动。

\section{模块化开发与调试技巧}

ES模块通过\texttt{export}和\texttt{import}建立清晰依赖。接口访问、业务计算和视图组件应分层组织，避免在组件中散布重复的网络代码。

\begin{lstlisting}[language=JavaScript]
// level.js
export function levelStatus(level, warning = 5.0) {
  return level >= warning ? "warning" : "normal";
}

// panel.js
import { levelStatus } from "./level.js";
console.log(levelStatus(5.12));
\end{lstlisting}

调试遵循“复现—缩小范围—验证假设—回归测试”的顺序。浏览器开发者工具中，Network面板用于检查请求、状态码和缓存；Sources面板可设置断点并查看调用栈；Console用于查看结构化日志；Performance面板用于定位长任务和频繁重排。代码中的临时\texttt{console.log()}不应作为生产日志方案。

\section{Vue 3组件化开发}

传统命令式写法需要在数据变化后手动寻找并更新多个DOM节点。水利仪表盘一旦包含曲线、表格和告警标识，这些更新容易分散。Vue使用响应式状态和声明式模板：开发者描述“状态如何映射为界面”，框架负责同步DOM。组件化仍需遵循可理解反馈和一致交互等基本设计原则\cite{norman2013}。

本章使用Vue 3.4+组合式API。\texttt{ref}适合基本值，\texttt{reactive}适合对象，\texttt{computed}表达派生状态；组件通过props接收数据，通过emit通知父组件。下面的单文件组件把状态声明、属性校验、模板绑定和事件发射放在同一示例中，便于沿着数据流理解组件边界。

\begin{lstlisting}[language=Vue]
<script setup>
import { computed } from 'vue'
const props = defineProps({
  name: { type: String, required: true },
  level: { type: Number, required: true }
})
const emit = defineEmits(['open-detail'])
const status = computed(() => props.level >= 5.0 ? 'warning' : 'normal')
</script>

<template>
  <article :class="['station-card', `station-card--${status}`]">
    <h3>{{ name }}</h3>
    <p>水位：{{ level.toFixed(2) }} m</p>
    <button type="button" @click="emit('open-detail')">查看详情</button>
  </article>
</template>
\end{lstlisting}

组件在创建、挂载、更新和卸载阶段提供生命周期钩子。Vue 3中卸载阶段使用\texttt{beforeUnmount}/\texttt{unmounted}或组合式API的\texttt{onBeforeUnmount}/\texttt{onUnmounted}，不使用Vue 2的\texttt{beforeDestroy}/\texttt{destroyed}。

\section{Vue Router与Pinia应用组织}

Vue Router把URL映射到页面组件。路由配置应包含稳定的路径、名称和组件；页面级组件可用动态导入实现按需加载。路由守卫适合做登录状态和角色检查，但细粒度业务权限仍须由后端验证。

\begin{lstlisting}[language=JavaScript]
import { createRouter, createWebHistory } from 'vue-router';

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', name: 'home', component: () => import('./views/Home.vue') },
    { path: '/stations/:id', name: 'station',
      component: () => import('./views/StationDetail.vue'),
      props: true, meta: { requiresAuth: true } }
  ]
});

router.beforeEach(to => {
  if (to.meta.requiresAuth && !sessionStorage.getItem('token')) return '/login';
});
export default router;
\end{lstlisting}

Pinia集中管理跨组件共享且具有业务含义的状态，如当前测站、实时读数和告警数量。只在单个组件内部使用的展开状态不必放入仓库。

\begin{lstlisting}[language=JavaScript]
import { defineStore } from 'pinia';

export const useStationStore = defineStore('station', {
  state: () => ({ currentId: null, latest: null, loading: false }),
  getters: {
    isWarning: state => (state.latest?.level ?? 0) >= 5.0
  },
  actions: {
    async loadLatest(id) {
      this.loading = true;
      try {
        this.latest = await loadLatestLevel(id);
        this.currentId = id;
      } finally {
        this.loading = false;
      }
    }
  }
});
\end{lstlisting}

应用入口依次注册Pinia和Router，再挂载根组件：

\begin{lstlisting}[language=JavaScript]
import { createApp } from 'vue';
import { createPinia } from 'pinia';
import App from './App.vue';
import router from './router';

createApp(App).use(createPinia()).use(router).mount('#app');
\end{lstlisting}

\section{Vite工程化与性能优化}

推荐目录按职责组织为\texttt{views/}、\texttt{components/}、\texttt{stores/}、\texttt{router/}和\texttt{api/}。开发阶段使用ESLint、格式化工具和单元测试；生产构建使用\texttt{vite build}生成带内容哈希的静态资源。

性能优化应先测量再行动：
\begin{itemize}
\item \textbf{代码分割}：页面组件使用\texttt{import()}动态导入，避免首屏下载全部业务代码；
\item \textbf{缓存}：带内容哈希的JS/CSS可设置长期强缓存，入口HTML采用协商缓存，实时接口按业务时效设置；
\item \textbf{构建}：通过包体分析识别大型依赖，按需引入图表组件，并设置合理的浏览器目标；
\item \textbf{运行时}：对高频输入防抖，对监测流批量刷新，避免无意义的深层监听。
\end{itemize}

\begin{lstlisting}[language=JavaScript]
// vite.config.js：明确生产构建目标并保留可追踪的分包名称
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';

export default defineConfig({
  plugins: [vue()],
  build: { target: 'es2020', sourcemap: true }
});
\end{lstlisting}

交付前至少验证：主要浏览器中的页面布局、接口失败与空数据状态、路由刷新、权限绕过、移动端触控、构建产物及控制台错误。

\section*{思考题与练习题}

\begin{enumerate}
\item[\textbf{客观题}]
\item HTML的主要职责是（\quad）。A. 表达内容结构与语义\quad B. 管理数据库\quad C. 编译Java代码\quad D. 配置消息队列
\item CSS Grid最适合（\quad）。A. 二维仪表盘布局\quad B. 发送HTTP请求\quad C. 解析JSON\quad D. 定义路由守卫
\item Promise进入fulfilled状态后仍可再次变为rejected。（判断：对／错）
\item Vue 3组件卸载后的清理逻辑宜放在（\quad）。A. onMounted\quad B. onUnmounted\quad C. computed\quad D. defineProps
\item Pinia最适合保存（\quad）。A. 跨页面共享的当前测站\quad B. 单个按钮的悬停颜色\quad C. HTML标题级别\quad D. CSS媒体查询
\item 使用动态\texttt{import()}可以支持页面级代码分割。（判断：对／错）

\item[\textbf{简答与设计题}]
\item 说明DOM树、CSSOM树、JavaScript引擎与渲染过程之间的关系。
\item 为水位、流量、雨量三类监测卡片设计语义化HTML和响应式Grid布局。
\item 分别用Promise链和async/await实现测站最新水位加载，并处理HTTP错误。
\item 设计“首页—测站详情—告警中心”的路由表，并说明哪些状态应放入Pinia。
\item 使用浏览器开发者工具定位一次接口缓慢和一次页面频繁重排问题，记录证据与修复结果。
\end{enumerate}
