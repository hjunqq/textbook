# 智慧水利教材转换器使用指南

## 🎯 解决方案概述

本转换器专门为《智慧水利平台架构与开发》教材设计，彻底解决了以下问题：

### 已解决的问题 ✅

1. **章节编号不一致** → 自动标准化章节标题和编号
2. **图片路径混乱** → 统一复制图片到指定目录，修复所有引用
3. **代码块缺少语言标识** → 自动检测并添加语言标识
4. **特殊格式转换问题** → 支持警告块、信息块等Markdown扩展语法
5. **Emoji显示问题** → 转换为LaTeX兼容的图标命令
6. **编码问题** → 自动检测和修复文件编码
7. **转换流程复杂** → 一键完成所有转换步骤

## 🚀 快速使用

### 方法1: 一键转换（最简单）

1. 双击运行 `一键转换.bat`
2. 等待转换完成
3. 查看 `publish/latex_output/` 目录下的结果

### 方法2: 命令行使用

```bash
# 基础转换
python 智慧水利教材终极转换器.py

# 使用配置文件
python 智慧水利教材终极转换器.py --config 智慧水利教材配置.json

# 指定输出目录
python 智慧水利教材终极转换器.py --output ./my_output
```

### 方法3: 转换前质量检查

```bash
python 教材质量检查器.py ../../docs/chapters
```

## 🔧 转换流程详解

### 1. 自动章节发现
- 扫描 `docs/chapters/` 目录
- 按 `chapter01`, `chapter02`, ... `chapter09` 顺序排列
- 每章包括主文件和节文件

### 2. 智能预处理
- **编码修复**：自动检测和转换文件编码
- **章节标准化**：统一章节标题格式
- **图片处理**：复制图片到统一目录，修复路径
- **代码块修复**：自动添加语言标识
- **特殊语法转换**：处理 `!!!` 风格的特殊块

### 3. Pandoc转换
- 使用专门的LaTeX模板
- 保持中文字体兼容性
- 添加代码语法高亮

### 4. PDF编译
- 多轮XeLaTeX编译处理交叉引用
- 自动处理目录和页码

## ⚙️ 配置选项

编辑 `智慧水利教材配置.json` 自定义转换：

```json
{
    "title": "智慧水利平台架构与开发",
    "author": "教材编写组",
    "latex_engine": "xelatex",
    "output_formats": ["pdf", "tex"],
    "preprocessing": {
        "fix_encoding": true,          // 修复编码问题
        "standardize_chapters": true,   // 标准化章节
        "unify_image_paths": true,     // 统一图片路径
        "fix_code_blocks": true,       // 修复代码块
        "convert_special_blocks": true  // 转换特殊块
    }
}
```

## 🐛 常见问题解决

### 问题1: 转换失败
**症状**: 脚本运行出错
**解决**: 
1. 检查Python环境
2. 确认Pandoc已安装
3. 查看错误日志

### 问题2: PDF编译失败
**症状**: tex文件生成了但PDF没有
**解决**:
1. 检查XeLaTeX安装
2. 确认中文字体可用
3. 检查图片文件完整性

### 问题3: 图片显示异常
**症状**: PDF中图片缺失或显示错误
**解决**:
1. 检查原始图片文件存在
2. 确认图片格式支持（PNG/JPG推荐）
3. 查看转换统计中的图片映射

### 问题4: 代码高亮不正确
**症状**: 代码没有语法高亮
**解决**:
1. 检查代码块是否指定语言
2. 确认支持的语言类型
3. 手动添加语言标识
