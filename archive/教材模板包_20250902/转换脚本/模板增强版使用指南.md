# 模板增强版转换器 - 使用指南

## 概述

模板增强版转换器是一个全功能的教材转换工具，能够自动将Markdown格式的教材内容转换为高质量的LaTeX文档，并自动应用预定义的模板样式。

## 主要功能

### ✅ 已实现的功能

1. **自动模式识别**：
   - 学习目标（`## 学习目标`）
   - 关键概念（`## 关键概念`）
   - 实践练习（`## 实践练习`）
   - 注意事项（`!!! warning "注意"`）
   - 章节摘要（`## 本章小结`）

2. **代码高亮增强**：
   - 自动识别编程语言（JavaScript、Python、Java、C#、SQL等）
   - 应用对应的语法高亮样式
   - 支持行内代码和代码块

3. **智能图标转换**：
   - 💡 → `\faLightbulb`
   - 🔑 → `\faKey`
   - ⚙️ → `\faCogs`
   - ⚠️ → `\faExclamationTriangle`
   - 等其他常用emoji转换

4. **统一图片管理**：
   - 自动收集所有章节的图片到统一目录
   - 修复和标准化图片路径引用
   - 支持多种图片格式（PNG、JPG、SVG、PDF等）

5. **文档结构优化**：
   - 自动生成完整的LaTeX文档结构
   - 应用中文字体配置
   - 包含所有必需的包和定义

## 使用方法

### 基本用法

```bash
python3 模板增强版转换器.py <源目录> -f latex -o <输出目录>
```

### 命令行选项

- `-f, --format`: 输出格式（latex、pdf、docx）
- `-c, --config`: 配置文件路径
- `-o, --output`: 输出目录
- `--no-template`: 不使用自定义模板
- `--no-enhancement`: 不应用样式增强

### 使用示例

```bash
# 转换整个项目为LaTeX
python3 模板增强版转换器.py /path/to/project -f latex -o output

# 转换为PDF（需要LaTeX环境）
python3 模板增强版转换器.py /path/to/project -f pdf -o output

# 使用自定义配置文件
python3 模板增强版转换器.py /path/to/project -c config.json -o output
```

## 支持的Markdown模式

### 学习目标
```markdown
## 学习目标

通过本章学习，学生将能够：
- 目标1
- 目标2
```

### 关键概念
```markdown
## 关键概念

**重要概念**：概念定义
```

### 实践练习
```markdown
## 实践练习

请完成以下练习：
1. 练习1
2. 练习2
```

### 注意事项
```markdown
!!! warning "注意"
    这里是需要注意的内容
```

### 章节摘要
```markdown
## 本章小结

本章介绍了...
```

## 配置选项

转换器支持通过配置文件自定义行为：

```json
{
  "output_format": "latex",
  "use_custom_template": true,
  "apply_style_enhancements": true,
  "preprocessing": {
    "apply_template_styles": true,
    "fix_code_blocks": true,
    "optimize_images": true
  },
  "postprocessing": {
    "fix_document_structure": true,
    "apply_custom_environments": true
  }
}
```

## 依赖要求

- Python 3.6+
- Pandoc（用于Markdown到LaTeX转换）
- XeLaTeX（如果需要PDF输出）
- FontAwesome5字体包（用于图标显示）

## 故障排除

### 常见问题

1. **编译错误**: 确保LaTeX环境完整安装
2. **字体问题**: 确认中文字体（SimSun、SimHei等）已安装
3. **图标显示问题**: 确认fontawesome5包已安装
4. **图片路径问题**: 转换器会自动统一图片路径，无需手动处理

### 调试模式

使用`--no-enhancement`参数可以禁用样式增强功能，方便调试基本转换问题。
