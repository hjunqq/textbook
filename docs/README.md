# 智慧水利平台架构与开发 - MkDocs版

这是使用MkDocs重新构建的《智慧水利平台架构与开发》教材。

## 使用说明

### 预览

```bash
# 激活conda环境
conda activate book

# 启动本地服务器
mkdocs serve
```

### 构建

```bash
# 构建静态网站
mkdocs build
```

### 部署

```bash
# 部署到GitHub Pages
mkdocs gh-deploy
```

## 目录结构

- `docs/` - 文档源文件
- `mkdocs.yml` - MkDocs配置文件
- `site/` - 生成的静态网站（在构建后会出现）
