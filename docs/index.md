## 教材简介

随着信息技术与水利行业的深度融合，智慧水利已成为推动水利现代化的重要方向。本教材旨在为水利专业学生提供全面的智慧水利平台架构与开发知识，培养具备现代软件开发能力的复合型水利人才。

### 教材特色

- **理论与实践结合**：既有扎实的理论基础，又有丰富的实践案例
- **技术与业务融合**：将软件技术与水利业务需求紧密结合
- **循序渐进**：从基础概念到实际应用，层层深入
- **紧跟时代**：涵盖最新的软件开发技术和智慧水利发展趋势

### 适用对象

- 水利工程专业本科大三年级学生
- 从事智慧水利系统开发的工程技术人员
- 对智慧水利技术感兴趣的相关专业人员

### 学习目标

通过本教材的学习，学生将能够：

1. **掌握软件工程基础知识**，了解现代软件开发的基本理念和方法
2. **熟练使用开发工具**，具备版本控制、协作开发等基本技能
3. **理解前后端开发**，能够开发简单的Web应用程序
4. **掌握三维场景构建技术**，能够创建水利工程的三维可视化场景
5. **具备系统设计能力**，能够参与智慧水利平台的架构设计和开发

- **调度决策支持**：水资源调度、防洪调度算法

部署后将提供在线版本进行学习，支持全文搜索、章节导航、代码高亮等功能。

### 本地开发

```bash
# 克隆代码仓库
git clone <仓库地址>
cd <仓库目录>

# 安装依赖 (使用 uv 或 pip)
uv sync
# 或者

uv run mkdocs serve

uv run mkdocs build

mkdocs build

# 产物位于 site/ 目录
```

## 📚 使用说明

### MkDocs 功能特性

- **响应式设计**：支持PC、平板、手机等多设备访问
- **全文搜索**：内置强大的全文搜索功能
- **代码高亮**：支持多语言语法高亮
- **数学公式**：支持 LaTeX 数学公式渲染
- **Mermaid图表**：支持流程图、时序图等图表绘制

### 导出电子书

```bash
# 安装 mkdocs-with-pdf 插件
pip install mkdocs-with-pdf

# 导出PDF (需要配置插件)
uv run mkdocs build
# PDF文件将在构建过程中生成
```

### 开发环境配置

```bash
# 安装开发依赖
uv add mkdocs
uv add mkdocs-material
uv add mkdocs-mermaid2-plugin
uv add pymdown-extensions

# 或使用 requirements.txt
pip install -r requirements.txt
```

### 自动部署

1. 推送代码到 `main` 分支
2. 自动触发 MkDocs 构建和部署流程
3. 几分钟后更新内容即可在线访问

部署配置文件位于 `.github/workflows/` 目录。
