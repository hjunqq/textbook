# 前言

!!! note "说明"

    **从一次水位观测开始**

    一条库水位观测从测站出发，经过采集网关、通信网络和数据服务，最终成为监测页面上的一个点。值班员点击这个点时，应能查到测点位置、观测时间、质量码和历史变化；水位超过阈值时，系统还要生成预警，记录复核与处置过程。

    完成这样的功能，需要把水文与工程知识写成数据字段、计算规则和程序流程。本书面向已学过一门编程语言、尚未系统学习软件工程与前后端开发的水利专业学生，从一次数据请求入手，逐步实现页面、接口、数据库与三维场景之间的协作。

## 课程定位

《国家水网建设规划纲要》提出“建设数字孪生水网”<sup>[[1]](references.md#ref1)</sup>。在工程实践中，监测感知、数据治理、模型计算与运行管理需要共同支撑防洪、供水和工程安全等任务。平台开发因此涉及两类相互关联的工作：解释水利业务的依据与约束，并将其实现为能够运行和检验的软件。

本课程衔接程序设计基础与水利工程应用。学生将练习从岗位访谈中提取需求，把需求转成接口与数据模型，再通过编码和测试实现功能。贯穿案例中的每个阶段都有交付物：需求说明、接口表、监测页面、后端服务、三维场景和集成验收记录。课堂讨论与实验围绕这些交付物展开。

## 内容与学习顺序

全书九章，按照**“打基础 $\rightarrow$ 学技术 $\rightarrow$ 做项目”**的思路组织，分为三个部分。

!!! tip "提示"

    **第一部分基础篇（第1–3章）**

    从智慧水利的概念出发，建立对平台整体架构的认知。然后进入软件工程的核心内容：需求怎么分析、系统怎么设计、架构怎么选型。这部分是后续所有开发工作的理论根基。

!!! tip "提示"

    **第二部分技术篇（第4–7章）**

    四章对应平台开发与可视化表达的核心技术链：

    - **前端**（第4章）：HTML/CSS/JavaScript基础，Vue.js框架开发，重点是如何构建水情数据展示界面

    - **后端**（第5章）：Spring Boot框架（Java 17 / Jakarta EE）、RESTful API、JPA持久化、事务、Spring Security认证与权限，以及消息队列

    - **三维场景**（第6章）：WebGL/Three.js三维渲染，GIS地图服务，BIM建模与数字孪生技术

    - **观测数据展示**（第7章）：监测数据面向三维场景的组织、可视化表达、交互与联动

    每个技术点都围绕水利监测平台的实际需求展开，代码示例均取自水利业务场景。

!!! tip "提示"

    **第三部分应用篇（第8–9章）**

    前两部分学到的方法与技术，在这里汇聚成完整的项目实践。第8章以**水利工程安全监测平台**为起点，从业务需求、总体架构和数据模型出发，完成前后端、三维场景、智能分析、部署与验收的完整链路；并在8.5节进一步演进到数字孪生水利平台，以流域、水网和工程三类入口贯通“预报、预警、预演、预案”。第9章回顾全书，并给出技术展望与后续学习指引。

## 学习方法

**运行、修改与验证**

学习代码清单时，先按说明运行并核对输出，再修改一个输入或配置，预测并观察结果，最后注入故障、说明原因。章末思考题用于检查概念之间的联系，实践题要求提交代码与验证记录。记录应包括输入、预期结果、实际结果和失败时的排查过程。

以下是几条具体建议：

1.  **按顺序学习。**各章内容前后衔接，第4–7章的开发与可视化技术依赖第1–3章的方法基础，第8章的综合实践又建立在第4–7章的技术基础上。不建议跳章阅读。

2.  **搭建本地开发环境。**学习前端章节时，准备好Node.js和VS Code；学习后端章节时，按Java 17和Spring Boot配置开发环境，Python用于生成练习数据。每次实验按当前阶段检查实际使用的页面、接口或数据库，记录其启动方式与预期输出。

3.  **组队做课程设计。**如果条件允许，建议3–4人组成开发小组，分工协作完成一个小型水利监测平台。前端、后端、三维场景各有分工，在协作中体会真实项目的开发流程。

4.  **查阅文档并验证。**遇到报错时，先记录完整错误和依赖版本，再查相应版本的官方文档。采用社区方案前，检查其输入条件与版本是否相符，并用同一故障重测；在实验记录中保留来源和验证结果。

## 适用对象

**适用读者**

本书以水利工程及相关专业高年级本科生为主要读者，兼顾研究生，以及有志于从事水利信息化、智慧水利平台开发的技术人员。

**先修知识**

学习本书前，你需要具备以下基础：

- 至少学过一门编程语言（C、Python或Java均可）

- 了解基本的数据结构概念（数组、链表、树等）

- 对水利工程有初步认识（水力学、水文学等先修课程）

- 了解基本的数据库概念与SQL语言（推荐但不强制）

本书也可作为水利行业技术人员了解平台开发技术的参考读物。
