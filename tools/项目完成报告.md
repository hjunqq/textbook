## 🚀 使用指南

### 基本使用

```bash
# 转换完整文档
python3 md2latex_converter.py

# 转换单个章节
python3 md2latex_converter.py --chapter 1

# 只转换前言
python3 md2latex_converter.py --preface

# 生成PDF
python3 md2latex_converter.py --pdf

# 验证环境
python3 md2latex_converter.py --validate

# 启用调试模式
python3 md2latex_converter.py --debug
```

### 高级选项

```bash
# 指定配置文件
python3 md2latex_converter.py --config config.yaml

# 指定输出目录
python3 md2latex_converter.py --output-dir /path/to/output

# 显示状态
python3 md2latex_converter.py --status

# 清理临时文件
python3 md2latex_converter.py --clean
```

### 运行测试

```bash
# 运行完整测试套件
python3 test_converter.py
```
