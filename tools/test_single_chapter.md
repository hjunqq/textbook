## 1.1 软件概述

软件是计算机系统中不可或缺的组成部分，它由一系列程序、数据及相关文档组成。

### 1.1.1 定义软件

软件（Software）是计算机系统中与硬件（Hardware）相对应的逻辑实体。

**软件的核心组成部分**

1. **程序（Program）：** 程序是软件的核心，是由一系列指令或语句组成的集合。

```python
def hello_world():
    """简单的Hello World函数"""
    print("Hello, World!")
    return "Hello, World!"

# 调用函数
if __name__ == "__main__":
    result = hello_world()
```

2. **数据（Data）：** 数据是程序运行过程中处理的对象。
